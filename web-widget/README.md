# Web-версия iWeather

Локальный CSS playground для точной настройки внешнего вида виджета перед переносом изменений в GNOME Shell.

## Запуск

Из корня проекта:

```bash
python3 -m http.server 4173 --directory web-widget
```

Затем откройте [http://localhost:4173](http://localhost:4173).

Для быстрой визуальной настройки редактируйте [`styles.css`](./styles.css). Все ключевые параметры собраны в начале файла в блоке `DESIGN TOKENS`: фон сцены, ширина и скругление виджета, прозрачность, цвета, типографика, разделители и размеры.

Сценарий [`app.js`](./app.js) содержит демонстрационные данные и локальные состояния: выбор почасовой карточки, стрелки прокрутки, обновление и подсказка для кнопки настроек. Данные не запрашиваются из сети — макет работает офлайн.

## Что переносить обратно в GNOME-версию

После CSS-правок достаточно прислать изменённый `web-widget/styles.css` и, при необходимости, скриншот. Классы в HTML названы по смысловым блокам (`.current-weather`, `.hour-card`, `.day-row`, `.range-track`), поэтому перенос геометрии и цветов в `iweather@local/stylesheet.css` будет прямым.

Визуальный ориентир ресерча сохранён рядом как [`research-concept-compact.png`](./research-concept-compact.png). Первый exploratory-вариант также оставлен как [`research-concept.png`](./research-concept.png).
